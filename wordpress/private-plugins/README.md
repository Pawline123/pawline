# Lizenzpflichtige Plugins (nicht im Repository)

Lege hier die ZIP-Datei von **Germanized Pro** ab (Download nach Kauf im vendidero-Kundenkonto),
z. B. `woocommerce-germanized-pro.zip`. Das Setup installiert jede ZIP-Datei in diesem Ordner.
ZIP-Dateien sind per `.gitignore` vom Repository ausgeschlossen. Der Lizenzschlüssel wird
im WordPress-Backend eingegeben, nicht in Dateien gespeichert.
